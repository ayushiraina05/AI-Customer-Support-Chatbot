# AI Customer Support Chatbot

## 📌 Project Overview
This project is a simple AI-powered customer support chatbot developed using Flask. 
It automates responses to customer queries using basic Natural Language Processing (keyword matching).

## 🚀 Features
- Automated customer support responses
- Keyword-based NLP processing
- Predefined FAQ handling
- Easy to extend with AI APIs

## 🛠 Technologies Used
- Python
- Flask
- HTML

## 📂 Project Structure
- app.py → Backend logic
- templates/index.html → Frontend interface
- requirements.txt → Dependencies

## 🔮 Future Enhancements
- Integration with OpenAI API
- Database connectivity
- Deployment on cloud platforms
